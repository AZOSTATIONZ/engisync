# Dashboard banner images (optional)

The dashboard banner cycles through 4 slides. Each has a coloured gradient by
default, and will show a **photo** if you add these files here:

- `slide1.jpg` — Electrical / electronics
- `slide2.jpg` — Mechanical / machines
- `slide3.jpg` — Civil / construction
- `slide4.jpg` — Computer / data center

## Free, licence-safe photos

Download from (all free, high-res, no attribution needed):

- **Unsplash** — https://unsplash.com/s/photos/engineering
- **Pexels** — https://www.pexels.com/search/engineering/
- **Pixabay** — https://pixabay.com/images/search/engineering/

Save each as `slide1.jpg` … `slide4.jpg` (JPG or PNG), keep them reasonably
small (< 400 KB each) so the dashboard stays fast, then commit + push.
If a file is missing, that slide just shows its gradient — nothing breaks.
