# Hero background video (optional)

Drop a short, looping, royalty-free engineering clip here as **`hero.mp4`**
(and optionally `hero.webm`) and the landing page will automatically play it
behind the hero, fading in over the animated canvas fallback.

## Where to get free, licence-safe clips

- **Pexels Video** — https://www.pexels.com/videos/ (free to use, no attribution)
- **Coverr** — https://coverr.co/ (free to use)
- **Mixkit** — https://mixkit.co/free-stock-video/ (free licence)

Search terms that fit: *engine running, gears, circuit board, factory machine,
robot arm, construction crane, blueprint, data center*.

## Tips

- Keep it **short (5–15s)** and **small (< 5 MB)** so it loads fast — trim/compress it.
- Mute is applied automatically (browsers require muted autoplay).
- If no file is here, the site uses the lightweight animated canvas instead —
  nothing breaks.
